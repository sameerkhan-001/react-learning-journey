# ⚛️ React Learning Journey

A hands-on journey of learning and practicing **React.js**, covering concepts from the fundamentals to more advanced topics.

This repository contains my chapter-wise practice, experiments, and projects that I built while learning React. The goal is to understand the concepts by actually implementing them rather than just following tutorials.

* State & `useState`
* Advanced State Handling
* Form Handling
* Two-Way Binding
* Local Storage
* API Calling

* React Router DOM
* Advanced Routing
* Context API
* Children as Props
* Light / Dark Theme
* And more as I continue learning React
